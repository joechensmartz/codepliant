1. Program Overview

Acme Inc is committed to maintaining a strong security posture through continuous employee education. This Security Awareness Program establishes a structured approach to training all personnel on security best practices, threat recognition, and incident response procedures.

Program Objectives:

  • Reduce human-factor security incidents by 80%+

  • Achieve 100% staff completion of annual security training

  • Maintain phishing simulation click rates below 5%

  • Ensure all staff can identify and report security incidents

  • Meet compliance requirements (SOC 2, ISO 27001, GDPR Art. 39)

3.1 Phishing Awareness

Duration: 45 minutes | Frequency: Quarterly refresher

Learning Objectives

  • [ ] Identify common phishing email indicators (sender spoofing, urgency tactics, suspicious links)

  • [ ] Recognise spear-phishing and business email compromise (BEC) attacks

  • [ ] Identify vishing (voice phishing) and smishing (SMS phishing) attempts

  • [ ] Know the correct procedure for reporting suspected phishing

  • [ ] Understand the consequences of successful phishing attacks

Key Topics

  1. Email indicators — hover-over URL inspection, sender verification, header analysis

  2. Common pretexts — IT support, CEO fraud, invoice scams, password resets

  3. Safe behaviour — never click suspicious links, forward to security team, verify via separate channel

  4. Real examples — anonymised examples from industry incidents

3.4 Social Engineering Defence

Duration: 30 minutes | Frequency: Semi-annually

  • [ ] Recognise pretexting, baiting, and tailgating techniques

  • [ ] Verify identity before sharing sensitive information

  • [ ] Challenge unknown visitors and report suspicious physical access

  • [ ] Never share credentials, even with "IT support"

  • [ ] Use callback verification for financial/sensitive requests

3.5 Device & Endpoint Security

Duration: 20 minutes | Frequency: Annually

  • [ ] Lock screens when leaving devices unattended

  • [ ] Enable full-disk encryption on all devices

  • [ ] Keep operating systems and applications up to date

  • [ ] Use only approved software and cloud services

  • [ ] Avoid public Wi-Fi without VPN for work activities

  • [ ] Report lost or stolen devices immediately

3.6 Data Handling & Classification

Duration: 30 minutes | Frequency: Annually

  • [ ] Understand data classification levels (Public, Internal, Confidential, Restricted)

  • [ ] Handle personal data per GDPR/privacy requirements

  • [ ] Use approved channels for sharing sensitive data

  • [ ] Never store sensitive data in unapproved locations (personal email, USB drives)

  • [ ] Apply clean desk policy for physical documents

3.7 AI Security & Data Ethics

Duration: 30 minutes | Frequency: Quarterly

  • [ ] Do not paste confidential data into external AI tools

  • [ ] Understand data retention policies of AI providers

  • [ ] Review AI outputs for sensitive data leakage before sharing

  • [ ] Follow the Acceptable AI Use Policy for approved AI tools

  • [ ] Report AI-generated content that may contain PII or biased outputs

3.8 Payment Card Security (PCI DSS)

Duration: 30 minutes | Frequency: Annually

  • [ ] Never store full card numbers, CVVs, or PINs

  • [ ] Use only PCI-compliant payment processors

  • [ ] Report any exposure of cardholder data immediately

  • [ ] Follow secure payment handling procedures
