1. Purpose

This Information Security Policy establishes the framework for protecting Acme Inc's information assets. It aligns with ISO 27001 and NIST CSF standards.

2. Scope

This policy applies to:

  • All information systems and data assets

  • All employees, contractors, and third-party users

  • All 8 integrated services detected in this project

3. Information Security Objectives

  • Confidentiality — Protect information from unauthorized access

  • Integrity — Ensure accuracy and completeness of information

  • Availability — Ensure authorized users have access when needed

5. Access Control

  • Principle of least privilege for all system access

  • Multi-factor authentication required for production systems

  • Access reviews conducted quarterly

  • Immediate access revocation upon role change or termination
